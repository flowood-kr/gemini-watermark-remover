개인정보 처리방침

시행일: 2026년 5월 20일

PixKit은 회원가입 없이 사용할 수 있으며, 사용자가 선택한 이미지·PDF 파일을 서버에 저장하지 않습니다. 기본 처리 과정은 사용자의 브라우저 안에서 실행됩니다.

1. 수집하는 개인정보

PixKit은 회원가입, 로그인, 결제, 댓글 기능을 제공하지 않으므로 이름, 이메일, 전화번호, 결제 정보와 같은 직접 식별 개인정보를 요구하지 않습니다.

2. 파일 처리와 저장

  • 사용자가 업로드한 이미지·PDF는 브라우저 메모리에서 처리됩니다.
  • 처리 결과 파일은 사용자의 기기에서 직접 생성되고 다운로드됩니다.
  • PixKit 서버는 업로드 파일 원본이나 결과물을 장기 저장하지 않습니다.

3. 네트워크 요청이 발생하는 경우

정적 웹사이트 파일, 이미지 URL 불러오기, AI 배경 제거 모델 다운로드, 폰트·라이브러리 로딩 과정에서 네트워크 요청이 발생할 수 있습니다. 외부 이미지 URL을 직접 입력하면 해당 이미지를 가져오기 위한 요청이 전송될 수 있으므로 민감한 URL은 사용하지 않는 것을 권장합니다.

4. 쿠키와 추적

현재 PixKit은 자체 회원 식별 쿠키를 사용하지 않습니다. 배포·호스팅 인프라가 보안, 캐시, 접속 안정성을 위해 기본 로그를 처리할 수 있으나, PixKit은 이를 개인별 프로필 생성 목적으로 사용하지 않습니다.

5. 보안 안내

공용 PC나 공유 브라우저에서 민감한 문서를 처리하는 경우, 작업 완료 후 다운로드 파일과 브라우저 캐시를 직접 확인해 삭제해 주세요. AI 모델은 브라우저 캐시에 저장될 수 있으며, 이는 다음 실행 속도를 높이기 위한 용도입니다.

6. 정책 변경

서비스 기능, 배포 방식, 법령 변경에 따라 본 방침이 업데이트될 수 있습니다. 중요한 변경이 있는 경우 이 페이지의 시행일과 내용을 갱신합니다.
