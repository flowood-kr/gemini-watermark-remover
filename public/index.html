사용 방법

각 도구의 단계별 사용 방법입니다. 펼쳐서 확인하세요.

🧼

Gemini 워터마크 제거 방법

소요 시간: 약 30초 · 비용: 무료

  1. 상단 모드 토글에서 "워터마크 제거"를 선택합니다.
  2. Gemini가 생성한 이미지를 업로드 박스에 드래그하거나, 이미지 URL을 붙여넣고 "불러오기"를 누릅니다.
  3. PixKit이 NanoBanana 워터마크를 자동으로 감지하고 역(逆) 알파 블렌딩 알고리즘으로 제거합니다.
  4. 결과를 미리보기에서 확인하고 "다운로드"를 눌러 깨끗한 이미지를 저장합니다.
🖼️

이미지 배경 제거 방법 (누끼따기)

소요 시간: 색상 모드 1초 · AI 모드 3~15초 · 비용: 무료

  1. 모드 토글에서 "배경 제거"를 선택합니다.
  2. 서브 모드에서 "색상 제거"(단색 배경) 또는 "AI 제거"(복잡한 배경)를 선택합니다.
  3. AI 모드에서는 ⚡ 빠름(isnet)(~80MB) 또는 ✨ 고품질(BiRefNet)(~180MB, 머리카락·털 정교) 중 선택합니다.
  4. 이미지를 업로드하면 자동으로 배경이 제거됩니다. 첫 사용 시 AI 모델이 다운로드되어 브라우저에 캐시되며, 다음부터는 즉시 실행됩니다.
  5. 투명 PNG로 다운로드하세요.
📄

PDF를 이미지로 변환하는 방법

소요 시간: 페이지당 1~3초 · 최대 50MB PDF · 비용: 무료

  1. 모드 토글에서 "📄 PDF 도구" → "🖼️ 이미지 변환"을 선택합니다.
  2. PDF 파일을 업로드 박스에 드래그하거나 클릭해 선택합니다.
  3. 포맷(PNG 무손실 또는 JPG 용량 작음)과 해상도(150·300·600 DPI)를 선택합니다.
  4. "이미지로 변환"을 눌러 모든 페이지를 처리합니다.
  5. 각 이미지를 개별 다운로드하거나, "전체 ZIP 다운로드"로 한 번에 받습니다.
✂️

PDF 페이지 순서 변경·삭제 방법

소요 시간: 약 1분 · 화질 손실 없음(무손실 재저장) · 비용: 무료

  1. 모드 토글에서 "📄 PDF 도구" → "✂️ 페이지 편집"을 선택합니다.
  2. 편집할 PDF를 업로드합니다. 페이지가 썸네일 그리드로 표시됩니다.
  3. 썸네일을 드래그해 순서를 바꾸거나, 우측 상단 × 버튼으로 페이지를 삭제합니다.
  4. "편집된 PDF 저장"을 누르면 원본 페이지 바이트가 그대로 복사되어 화질 손실 없이 새 PDF로 저장됩니다.

자주 묻는 질문

PixKit은 정말 무료인가요?
네, 모든 기능을 무료로 이용할 수 있습니다. 워터마크 제거, AI 배경 제거, PDF 변환·편집까지 횟수·용량 제한 없이 사용 가능합니다. 회원가입·결제 정보 입력도 필요 없습니다.

업로드한 파일이 서버에 저장되나요?
아니요, 업로드하신 이미지·PDF는 서버로 전송되지 않습니다. 워터마크 제거, AI 배경 제거, PDF 변환·편집 등 모든 처리는 여러분의 브라우저 안에서 실행되며 결과물도 로컬에서 직접 생성됩니다.

회원가입이나 로그인이 필요한가요?
필요 없습니다. PixKit은 별도 가입·로그인 절차 없이 접속 즉시 모든 도구를 사용할 수 있습니다. 이메일·전화번호 등 어떤 개인정보도 수집하지 않습니다.

Gemini 워터마크 제거의 원리는 무엇인가요?
Gemini가 이미지 우측 하단에 합성하는 NanoBanana 워터마크는 알려진 색·투명도·위치를 가집니다. PixKit은 이 합성 방식을 역(逆)으로 적용해 원본 픽셀값을 복원하는 알파 블렌딩 알고리즘을 사용합니다. AI 추론이 아니라 수학적 역연산이므로 화질 손실이 없습니다.

AI 배경 제거의 isnet과 BiRefNet은 어떤 차이가 있나요?
isnet(빠름)은 약 80MB 모델로 일반적인 인물·제품 사진에 적합합니다. BiRefNet-lite(고품질)는 약 180MB로 머리카락·털·복잡한 외곽선까지 훨씬 정교하게 분리합니다. 두 모델 모두 한 번 다운로드되면 브라우저에 캐시되어 다음부터는 즉시 동작합니다. WebGPU 지원 브라우저에서 더 빠르게 처리됩니다.

PDF 파일 크기 제한이 있나요?
최대 50MB까지 지원합니다. 페이지 수에는 별도 제한이 없으나 매우 많은 페이지를 600 DPI로 변환할 경우 브라우저 메모리에 부담이 갈 수 있어 150·300 DPI를 권장합니다. 페이지 편집은 원본 바이트를 그대로 재저장하므로 페이지 수에 관계없이 화질이 유지됩니다.

모바일에서도 사용 가능한가요?
네, 모바일 Chrome·Safari에서 모든 기능이 동작합니다. 다만 AI 배경 제거는 모델 다운로드 용량(80~180MB)과 메모리 사용량이 크기 때문에 Wi-Fi 환경에서 첫 사용을 권장합니다. PDF 600 DPI 변환은 데스크톱이 더 빠릅니다.

어떤 브라우저를 사용해야 가장 빠른가요?
AI 배경 제거는 WebGPU를 지원하는 최신 Chrome·Edge에서 GPU 가속이 적용되어 가장 빠릅니다. Safari·Firefox에서도 동작하지만 WASM(CPU) 폴백이 사용되어 다소 느립니다. Canvas Fingerprint Defender 같은 확장 프로그램이 활성화된 경우 처리 오류가 발생할 수 있으니 일시 비활성화를 권장합니다.

개인정보 안내

업로드하신 파일은 우리 서버에 저장되지 않습니다. 이미지·PDF의 모든 처리(워터마크 제거, 배경 제거 AI, PDF 변환·편집)는 여러분의 브라우저 안에서 실행되며, 다운로드 결과물 역시 로컬에서 생성됩니다.
